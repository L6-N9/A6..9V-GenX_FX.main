## 🎮 Usage

### Quick Start
```bash
# 1. Configure environment
export WHATSAPP_GROUP_URL="https://chat.whatsapp.com/DYemXrBnMD63K55bjUMKYF"

# 2. Send a signal
python -c "
from services.notifier import send_signal
signal = {
    'symbol': 'XAUUSD',
    'action': 'BUY',
    'entry': 2650.50,
    'target': 2680.00,
    'stop_loss': 2630.00,
    'confidence': 85,
    'timestamp': '2024-01-04T12:00:00'
}
send_signal(signal)
"
```

### Integration in Code
```python

# Send trading signal

# Send system notification
send_notification("Alert", "System is operational")
```
